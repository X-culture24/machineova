## CRITICAL for Image Clarity:
1. **Use 2x resolution**: If displaying at 400x250px, save at 800x500px
2. **PNG format only** - No compression artifacts
3. **High quality source images** - Don't upscale low-res images
4. **Optimize after saving** - Use tools like TinyPNG to reduce file size without quality loss

## If images are still blurry:
- Check if your source images are high resolution
- Ensure you're not scaling up small images
- Use professional photo editing software to export at high quality
